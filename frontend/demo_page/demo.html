Step 7 of 10 · Key Step

Cloud Configuration

This is where you configure your personal cloud storage settings:

👤 Owner Name: Your display name shown in the Control Panel and to Wi-Fi peers. Default: Windows username.
📁 Storage Folder: Where all cloud files will live. Tip: Point this to an external USB or secondary hard drive for massive storage!
🔑 Server Password: Master password used to log in from any web browser on your phone, tablet, or remote PC.
🌐 Subdomain (Pro Only): Claim a permanent custom web address (e.g., https://yourname.loca.lt).
📏 Storage Quota: Optional maximum limit in GB (leave blank / 0 for no limit).

Feature Guide

Using Your Cloud — Core Features

Master every aspect of file organization, media playback, smart sharing, and Wi-Fi transfers.

📤

Uploading Files & Nested Folders

Drag-and-Drop & Resilient Chunked Engine
  • Drag & Drop: Drag files or entire folders straight from Windows File Explorer and drop anywhere on the browser window.
  • Preserved Hierarchy: Subfolders and deep directory trees are created automatically on your disk with exact folder structures intact.
  • Chunked Large Uploads: Multi-gigabyte files (10GB+) are automatically split into resilient streaming chunks. If Wi-Fi drops momentarily, only the current chunk is retried!
  • Staging Queue: Review total file count and payload size before upload starts.
📥

Downloading & Multi-File ZIP

Single-Click & Batch Archives
  • Single File: Click any file name or the download arrow icon (↓) to download immediately.
  • Batch ZIP Bundling: Select multiple files with checkboxes → click "Download" in the toolbar. PrivCloud instantly packages them into a single ZIP archive.
  • Full Speed: Local Wi-Fi transfers occur at maximum Gigabit LAN speed with zero throttling.
🗂️

File Organization & Navigation

Breadcrumbs, Search & Sidebar
  • Breadcrumb Navigation: Easily traverse deep nested folder structures with clickable breadcrumb pills.
  • File Operations: Right-click or long-press any item to Rename, Move, Copy, or Delete with instant confirmation.
  • Instant Search: Filter across thousands of files in real time as you type in the search bar.
  • ⭐ Bookmarks & Favorites: Star any essential folder or document for 1-click access from the sidebar.
  • Pre-Organized Folders: Quick sidebar shortcuts to Documents, Movies, Photos, Videos, Projects, and Shared.

Smart Sharing & Client Dropboxes

Expiring Links, Passwords & Dropboxes
  • Expiring Links: Set link lifetime to 1 hour, 24 hours, 7 days, 30 days, or Never.
  • Password Security: Require recipients to enter a custom password before previewing or downloading.
  • Centralized Share Dashboard: View all active links with live countdown timers and 1-click Revoke.

Wi-Fi Peer Discovery & Radar

Zero-Config Gigabit Transfers

Lifecycle & Maintenance

System Operations & Maintenance

Straightforward procedures for changing passwords, stopping the server, upgrading editions, and clean removal.

🔑

How to Change Password

From Desktop Control Panel: Open Control Panel → Switch to Storage & Security tab → Enter new password → Click Save Settings (or press Ctrl+S).
From Web Dashboard: Open dashboard → Go to Settings page → In Change Password section, enter current and new password → Click Save.
⏹️

Stopping Your Cloud Server

When you want to stop the server before shutting down your PC:

  • Click the red "⏹ Stop Server" button in the Control Panel, or double-click the "Stop PrivCloud" desktop shortcut.
  • What happens: Server status turns red. Remote and LAN access is paused.
  • Data Safety: 100% of your stored files remain completely untouched and safe on your drive.
  • Auto-Start: If auto-start is enabled, PrivCloud resumes automatically on next PC boot!
🚀

Upgrading Your Edition

Upgrade from Free Trial → Basic, or Basic → Pro with zero reinstallation:

  • Open the web dashboard or Desktop Control Panel.
  • Click "Activate Key" or "Upgrade License".
  • Paste your new license key → Click Activate.
  • New capabilities (such as custom subdomains, upload dropboxes, and 4K streaming) unlock instantly with zero downtime and zero data migration needed.
🗑️

How to Uninstall PrivCloud

If you ever need to remove PrivCloud from your PC:

1. Launch Uninstaller: Search "PrivCloud Uninstall" in Windows Start Menu or double-click Uninstall.bat.
2. Choose to Keep or Delete Files:
  • "No" (Recommended): Application files and shortcuts are removed, but all your files, photos, and folders remain safe on your drive.
  • "Yes": Deletes storage folder permanently (requires confirmation typing).
3. Finish: Click Uninstall. The uninstaller removes program files and firewall rules cleanly.
