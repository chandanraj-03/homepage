# ☁️ PrivCloud — Personal Cloud & File Management Platform

PrivCloud is a modern, feature-rich personal cloud storage and remote file management platform designed to provide a centralized hub for storing, organizing, previewing, and sharing digital assets.

---

## 🌟 Key Feature Highlights

### 📁 File & Folder Management
* **Comprehensive File Operations** — Create folders, rename, move, copy, and delete files and directories.
* **Interactive Folder Picker** — Intuitive modal browser to select exact target destinations when moving or copying items.
* **Multi-Select & Bulk Actions** — Select multiple items simultaneously to perform bulk deletions, bulk moves, or bulk downloads.
* **One-Click ZIP Archiving** — Download multiple files or entire folder trees packaged as a single compressed archive.
* **Detailed Metadata Display** — Instant visibility into file sizes, item counts, file types, and modification timestamps.

---

### 📤 Upload & Ingestion System
* **Drag-and-Drop Anywhere** — Full-screen drop overlay to upload files or directories by dropping them anywhere on the dashboard.
* **Preserved Folder Uploads** — Upload entire nested directory structures while preserving all subfolder hierarchies.
* **Chunked File Transfer** — Resilient multi-part uploading designed for smooth transfer of large files with progress monitoring.
* **Upload Staging & Queue Management** — Review staged files, see file counts, and clear or add items before starting uploads.
* **Real-Time Progress Tracking** — Visual progress bar indicating live upload percentage and transfer status.

---

### 👁️ In-Browser Preview & Media Suite
* **Interactive Image Gallery**:
  * High-resolution image preview modal.
  * Image navigation controls (Previous / Next).
  * Zoom In, Zoom Out, and 1:1 original scale reset.
  * 90° image rotation.
  * Automated slideshow playback mode.
* **Audio & Video Streaming** — Native media players with full seek, volume, and playback controls without external software.
* **Document & PDF Viewing** — Built-in PDF reader for viewing documents directly within the browser.
* **Markdown Rendering** — Rich formatting preview for documentation, readmes, and markdown notes.
* **Spreadsheet & Tabular Data Viewer** — Clean table presentation for CSV and TSV spreadsheet data.
* **Code & Text Inspection** — Formatted viewer for plain text, JSON structures, scripts, and source files.

---

### 🔗 Smart Sharing & Collaboration
* **Dual Sharing Modes**:
  * **Download Links** — Generate shareable links for specific files so external users can access and download them.
  * **Upload Links (File Dropboxes)** — Create collaborative shared folders allowing external users to upload files and folders directly.
* **Link Expiration Controls** — Configure shares to automatically expire after 1 hour, 24 hours, 7 days, 30 days, or keep them active indefinitely.
* **Access Passwords** — Protect shared links with optional custom passcodes.
* **QR Code Generation** — Generate instant QR codes for any share link for easy mobile device access.
* **Centralized Share Management** — Dedicated management dashboard to monitor all active links, check expiration countdowns, and revoke access at any time.

---

### 📊 Storage Analytics & Quota Management
* **Real-Time Capacity Meter** — Live storage bar showing used space, available free space, total capacity, and utilization percentage.
* **Visual Storage Breakdown** — Color-coded file categorization visualizing distribution across Images, Videos, Documents, Audio, Archives, Code, and Spreadsheets.
* **Storage Quota Controls** — Configurable storage limits with capacity safeguards to prevent disk exhaustion.

---

### 🔍 Search, Organization & Navigation
* **Favorites System** — Star frequently accessed files and folders for instant one-click retrieval via the Favorites tab.
* **Live Search** — Fast, real-time search across the file hierarchy.
* **Multi-Attribute Sorting** — Sort files by Name, Modification Date, Size, or File Type in ascending or descending order.
* **Dual View Modes** — Switch seamlessly between visual Grid View (with previews and thumbnails) and compact List View.
* **Interactive Breadcrumbs** — Clickable breadcrumb navigation bar for jumping to parent folders.
* **Category Shortcuts** — Quick-filter sidebar links for Documents, Photos, Movies, Videos, and Projects.

---

### 🎨 User Experience & Interface
* **Modern Dark & Light Themes** — Toggle between dark and light themes with saved user preferences.
* **Responsive Layout** — Adaptive UI designed for desktop screens, tablets, and mobile devices with collapsible navigation.
* **Contextual Feedback & Toasts** — Notification toasts confirming all file actions and background operations.
* **Account Settings** — In-app settings page to customize user credentials and server configurations.
